# AGENTS.md - internal/auth

## 职责

**本地控制面凭据**：生成、持久化、读取并校验 daemon 与本机客户端共享的控制令牌。

## 关键设计

- 控制令牌是 256 位随机值，以小写十六进制存放在 DataDir 下的 `control.token`。
- 首次创建通过同目录临时文件和原子发布完成，并发启动只能发布一个稳定令牌。
- 缺失的数据目录以 `0700` 创建；既有目录模式保持不变。
- 读取时严格校验普通文件、`0600` 权限和固定格式。
- HTTP Bearer 比较使用常量时间比较。

## 约束

- 本包只管理控制令牌，不依赖 API、daemon 或 session。
- 禁止记录、返回到 HTTP 响应或以命令行参数传递令牌。
- per-session signal token 不属于本包的控制令牌文件。
